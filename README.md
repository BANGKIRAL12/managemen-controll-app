## Instalasi
Kami menggunakan node.js untuk pondasi web dan server local. pastikan anda telah menginstal node.js di komputer local anda.
> Notes  
> Gunakan node.js 12 atau lebih baru (LTS)  
> Gunakan npm. karna project ini di bangun dengan npm bukan yarn atau pnpm


1.**clone repository**
```bash
git clone https://BANGKIRAL12/managemen-controll-app
```
_pastikan anda memiliki git._

2.**install semua peckage yang di perlukan**
```bash
npm install
```
_projek ini di bangun menggunakan npm. untuk penggunaan yarn atau pnpm kalian dapat menginstall nya manual dependecis yang di gunakan di bagian sedikit ke bawah di halaman ini._

3.**jalankan projek**
```bash
npm start
```
_untuk memulai project yang secara default terbuka di `http://localhost:1234`._  
**atau**
```bash
npm run dev
```
_untuk pengembangan dan uji coba._
