Untuk menampilkan dua halaman berbeda di URL yang berbeda di React tanpa melakukan reload, kamu bisa menggunakan `react-router-dom`. Berikut adalah langkah-langkah yang dapat kamu ikuti:

1. **Instal `react-router-dom`**: Jika belum diinstal, jalankan perintah berikut di terminal:

 ```bash
 npm install react-router
   ```

2. **Setup Router**: Buat file `App.js` atau di file utama komponen kamu, lalu buat routing menggunakan `BrowserRouter`, `Routes`, dan `Route`.

   Berikut adalah contoh implementasinya:

   ```javascript
   import React from 'react';
   import { BrowserRouter as Router, Routes, Route, Link } from 'react-router-dom';

   const HalamanA = () => {
       return <h1>Ini Halaman A</h1>;
   };

   const HalamanB = () => {
       return <h1>Ini Halaman B</h1>;
   };

   const App = () => {
       return (
           <Router>
               <nav>
                   <Link to="/a">Halaman A</Link>
                   <Link to="/b">Halaman B</Link>
               </nav>
               <Routes>
                   <Route path="/a" element={<HalamanA />} />
                   <Route path="/b" element={<HalamanB />} />
               </Routes>
           </Router>
       );
   };

   export default App;
   ```

3. **Jalankan Aplikasi**: Setelah kamu mengatur routing seperti di atas, jalankan aplikasi React kamu. Sekarang, saat mengklik tautan "Halaman A" atau "Halaman B", konten akan berganti sesuai dengan URL yang dipilih tanpa melakukan reload halaman.

Dengan menggunakan `react-router-dom`, kamu dapat mengelola navigasi antar halaman dengan mudah di aplikasi React.

Jika kamu ingin menggunakan tombol kustom alih-alih elemen link standar (`<Link>`), kamu bisa menggunakan komponen `useNavigate` dari `react-router-dom`. Berikut adalah cara melakukannya:

1. **Impor `useNavigate`**: Tambahkan impor `useNavigate` ke dalam file komponen kamu.

2. **Buat Fungsi untuk Navigasi**: Gunakan `useNavigate` untuk membuat fungsi yang akan memanggil navigasi ke URL yang diinginkan.

Berikut adalah contoh implementasinya:

```javascript
import React from 'react';
import { BrowserRouter as Router, Routes, Route, useNavigate } from 'react-router-dom';

const HalamanA = () => {
    return <h1>Ini Halaman A</h1>;
};

const HalamanB = () => {
    return <h1>Ini Halaman B</h1>;
};

const App = () => {
    return (
        <Router>
            <div>
                <TombolNavigasi tujuan="/a" label="Ke Halaman A" />
                <TombolNavigasi tujuan="/b" label="Ke Halaman B" />
            </div>
            <Routes>
                <Route path="/a" element={<HalamanA />} />
                <Route path="/b" element={<HalamanB />} />
            </Routes>
        </Router>
    );
};

const TombolNavigasi = ({ tujuan, label }) => {
    const navigate = useNavigate();

    const handleClick = () => {
        navigate(tujuan);
    };

    return (
        <button onClick={handleClick}>
            {label}
        </button>
    );
};

export default App;
```

Dalam contoh di atas:
- `TombolNavigasi` adalah komponen yang menerima `tujuan` dan `label` sebagai props.
- Ketika tombol diklik, fungsi `handleClick` akan memanggil `navigate(tujuan)` untuk berpindah ke halaman yang sesuai tanpa melakukan reload.

Dengan cara ini, kamu dapat menggunakan tombol kustom untuk navigasi antar halaman dalam aplikasi React-mu.
